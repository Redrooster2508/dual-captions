# Session log 2026-11-27

How the project was built, request by request. Commits are in [[Changelog]].

## 1. "Create my own language learning tool, allow dual captions when watching videos on netflix/youtube etc"
- Built a Chrome extension rather than a website, because only an extension can read the players' subtitle data and draw over the video. See [[Decisions]] and [[Architecture]]
- Adapters for [[YouTube]], [[Netflix]] and any other HTML5 video, plus dropped subtitle files ([[Other sites and subtitle files]])
- [[Machine translation]] for lines with no human translation: Chrome on-device by default, DeepL optional
- Click-a-word popup, shortcuts, pause on hover, blurred translation, pause after each line

## 2. "Add a 'library' to store words learnt or important" (sent while request 1 was being built)
- The planned saved-words list became the [[Library]]: Learning / Learnt status plus ★ Important, notes, the sentence and a link back to the moment, search and filters, flashcard review, CSV / JSON export and restore, add by hand
- Saved words are highlighted in the captions

## Testing and fixes
- Parser unit tests, plus Playwright suites for a local video page, the Library page, simulated YouTube and Netflix pages, and a stand-in DeepL. See [[Testing]]
- Fixed from what the tests and screenshots showed:
  - The translation line appeared a beat after the subtitle line: the two tracks now load in parallel
  - The popup's DeepL key field and the Library's add form showed when they should have been hidden (`display` overrode `hidden`)
  - On pages with native video controls, the captions covered the control bar
  - Library: scroll arrows on the inline text boxes, a stray scrollbar on the tabs, and the Important tab cut off on phones
  - **YouTube:** right after the page loads, the player asks for captions before it has its token. Immediate retries all failed and the caption line stayed empty. Token-less URLs are now a last resort and loading backs off
- Real YouTube blocks the automated browser (even its own captions come back empty), and getting past that was ruled out. Real Netflix needs an account. Both are still to be checked by hand ([[Known issues and next steps]])

## 3. "Push this to git" / "Create an obsidian vault" / README: why it was built
- README "Why I built this": a big interest in learning new languages, and existing services' paywalls felt like a big restriction
- This vault, laid out like the women's football project's
- Pushed to GitHub as `Redrooster2508/dual-captions`

## 4. "Languages have different words, eg Spanish in Europe vs Mexican vs PR Spanish is different; make sure this and other languages are accounted for"
- Languages became tags with an optional region, and tracks, translations, voices and dictionaries match by closeness. Details in [[Regional varieties]]
- Checked first:
  - DeepL accepts `ES-419` (Latin American Spanish) as a target
  - the *Diccionario de americanismos* page for *guagua* lists the Puerto Rico meaning (bus) apart from the Chile one (baby)
  - Priberam marks Brazilian usage
- Library entries are per region, so the same word can be saved for Puerto Rico and for Spain with different meanings
- Fixed along the way: YouTube's `iw` (Hebrew) and other old codes didn't match the popup's languages
- Tests: unit tests for matching and engine targets, a new browser suite (32 checks), and all earlier suites rerun
- Fixed from screenshots:
  - the word popup's region picker was cut off
  - the Library add form squeezed the region select
  - the region chips stretched on phones
- Pushed as `d7b879f` (code) and `5eece6e` (vault)

## 5. "It works on YouTube"
- Checked by hand on real YouTube: it works. Netflix is still to be checked ([[Known issues and next steps]])

## 6. "Catalan"
- Catalan wasn't in the language list at all. It's now there, with Catalonia, Valencia and Andorra as regions ([[Regional varieties]])
- Balearic is left out: it has no standard language tag
- Examples were checked on Wiktionary before going into the LinkedIn post:
  - *sortir* is the standard "to go out" and *eixir* the Valencian
  - *al·lot* ("boy") is Mallorcan, so it couldn't be a region you pick
  - *xiquet* is only marked "western Catalan", so it wasn't used

## 7. "Any other languages to add together to push in 2.1"
- Chosen from the suggestions:
  - Galician and Basque, Spain's other co-official languages
  - Irish and Welsh
  - Persian regions (Iran and Afghanistan)
- Not chosen: more Indian languages (Gujarati, Marathi, Punjabi, Telugu, Kannada, Malayalam)
- Irish, Welsh, Galician and Basque have no region choice, because their dialects have no standard tags
